# 技术栈说明

## 后端技术栈
- **框架**: FastAPI
- **ORM**: SQLAlchemy 2.0
- **数据库**: MySQL 5.4
- **缓存**: Redis
- **认证**: JWT
- **数据验证**: Pydantic v2

## 前端技术栈
- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **图表**: ECharts

## 项目结构
```
retail-franchise-system/
├── backend/          # 后端服务 (FastAPI)
├── frontend/         # 前端项目 (Vue 3)
├── database/         # 数据库脚本
└── docs/            # 项目文档
```
