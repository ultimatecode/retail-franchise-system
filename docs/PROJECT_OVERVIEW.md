# Sunday Space零售管理系统 - 项目概览

## 项目简介
Sunday Space零售管理系统，用于管理多加盟商的零售业务。

## 核心功能模块
- **商品管理**：商品信息、分类、库存管理
- **订单管理**：订单创建、状态跟踪、结算
- **加盟商管理**：加盟商信息、权限管理、业绩统计
- **库存管理**：入库、出库、调拨、盘点
- **报表统计**：销售报表、库存报表、财务报表
- **系统管理**：用户、角色、权限配置
